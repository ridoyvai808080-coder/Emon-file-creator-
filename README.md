# STIRLAX MODZ Web

A responsive static web recreation inspired by the supplied STIRLAX MODZ APK UI.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will publish `index.html`.

## Important

This is a frontend UI demo. The login password is currently set to the requested demo password and is checked in the frontend. This is not secure for production because the password can be discovered from the JavaScript source.

To make real key validation, connect `app.js` to your own secure backend/API. Do not put private API secrets directly in the JavaScript files.

The extracted app icon is included as `assets/logo.png`.
